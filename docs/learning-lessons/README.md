# Learning Lessons

Licoes aprendidas, pegadinhas e achados registrados durante o desenvolvimento
(constituicao, Principio V — Conhecimento Vivo). Cada licao descreve: contexto,
o que aconteceu, causa raiz e como evitar.

## Indice

(vazio — registros conforme surgirem)

## Formato

```markdown
# LL-AAAA-MM-DD: Titulo curto

## Contexto
Onde/quando aconteceu.

## O que aconteceu
Sintoma observado.

## Causa raiz
Diagnostico verificado.

## Como evitar
Acao concreta.
```
